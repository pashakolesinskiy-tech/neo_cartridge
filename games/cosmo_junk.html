Сервер не отвечает

Cosmo Junk — сетевая кооп-игра. Консоль показывает её через iframe, поэтому рядом должен быть запущен сервер игры.

Запуск сервера — без установки

Откройте PowerShell и выполните:

# перейти в папку игры (внутри neo_cartridge) cd D:\Projects\Gemini\neo_cartridge\games\cosmo-junk-game-concept # автономный сервер: без npm install и без PostgreSQL node standalone\server.js

Игра поднимется на http://localhost:3000. Другой порт — так же, с номером: node standalone\server.js 3100. Комнаты живут в памяти, рекорды — в standalone\data\leaderboard.json.

Полная версия (Next.js + PostgreSQL)

Если нужна оригинальная сборка — рабочая копия D:\Projects\cosmo-junk-game-concept:

cd D:\Projects\cosmo-junk-game-concept npm install npm run dev # PostgreSQL быстрый путь — docker compose из папки игры: # docker compose up -d

Адрес игры

Подсказка: адрес можно передать параметром в URL консоли — cosmo_junk.html?url=http://localhost:3001. Выбранный адрес запоминается в браузере.
