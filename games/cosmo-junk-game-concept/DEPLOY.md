# КАК ИГРАТЬ ОНЛАЙН · КОСМО-ХЛАМ

## 0. Короткий ответ

Игра онлайновая «из коробки»: все устройства общаются через сервер по обычному HTTPS.
P2P и общего Wi-Fi НЕ нужно. Нужно только, чтобы у всех открывался один и тот же URL.

## 1. Три способа собрать партию

### А. Один экран + телефоны рядом (классика)
1. Открой сайт на ПК/ТВ → «СОЗДАТЬ КОРАБЛЬ».
2. Друзья сканируют QR или вводят 4-буквенный код на своих телефонах.
   Работает на любом интернете: Wi-Fi, мобильная сеть, хоть через другую страну.

### Б. Полностью удалённо (Discord-квартирник)
1. Хост открывает игру у себя и **транслирует вкладку в Discord / Google Meet / Zoom**.
2. Остальные заходят по QR/ссылке со своих телефонов из дома — панели прилетают им по сети.
3. Орать инструкции — голосом в звонке. Задержка трансляции (~1–2 с) только добавляет хаоса.

### В. Быстрый тест в одиночку
Открой `/ship/КОД` на компьютере и `/play/КОД` во вкладке телефона или втором браузере —
играть можно даже одному за все роли (больно, но честно).

## 2. Свой сервер

### Самый простой путь — Docker Compose (поднимет и игру, и PostgreSQL)

```bash
docker compose up -d --build
docker compose logs -f app   # смотреть запуск
```

Игра: http://localhost:3000 (на VPS — http://IP-СЕРВЕРА:3000).
Остановить: `docker compose down`. Данные лидерборда живут в volume `pgdata`.

### Ручной Docker (если PostgreSQL уже есть)

```bash
docker build -t cosmo-junk .
docker run -d --name cosmo \
  -p 3000:3000 \
  -e DATABASE_URL="postgresql://user:pass@host:5432/cosmo" \
  cosmo-junk
```

### Вообще без Docker (локально, Node.js 20+)

```bash
npm ci

# подними PostgreSQL любым способом, например одноразовым контейнером:
docker run -d --name cosmo-pg -p 5432:5432 \
  -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=app_db postgres:16-alpine

# файл .env в корне проекта:
echo 'DATABASE_URL="postgresql://postgres:postgres@127.0.0.1:5432/app_db"' > .env

npm run build                  # продакшн-сборка
node scripts/ensure-db.mjs     # создать таблицу лидерборда
npm start                      # сервер на :3000
```

Для разработки вместо build/start: `npm run dev` (+ один раз `npx drizzle-kit push`).

Контейнер при старте сам создаст таблицу `leaderboard` (scripts/ensure-db.mjs).
Повесь перед ним любой HTTPS-прокси (Caddy/Nginx/Traefik) — HTTPS важен для
буфера обмена и стабильной работы вибрации на телефонах.

Подойдут Railway, Fly.io, Render, Timeweb Cloud, selectel — везде, где есть
«приложение Node.js + Postgres». Главные правила:

- **Ровно один инстанс.** Комнаты живут в памяти Node-процесса. Serverless
  и мульти-инстанс сломают игру (запросы друзей попадут на разные копии).
- `DATABASE_URL` → managed PostgreSQL (Neon, Supabase, Railway PG, ...).
- Рестарт сервера = текущие комнаты забываются (зал славы в БД — сохраняется).

## 3. Латентность

Ввод с телефона → экран: ~150–500 мс по интернету. Для жанра «кричим друг другу
инструкции» это нормально и даже смешно. Для турнирных киберкосмонавтов — хостите
сервер ближе к игрокам.
