# NEO-CARTRIDGE // 零 (Zero-Server Arcade Console)

**NEO-CARTRIDGE** — полноразмерная ретро-футуристическая игровая консоль и платформа, работающая на **100% в браузере клиента** без единого сервера, облачной базы данных или внешних зависимостей.

---

## 🕹️ Архитектурные принципы Zero-Server (Local-First):

1. **Процедурный чиптюн-синтезатор (Web Audio API)** ([`js/audio.js`](js/audio.js)):
   - **0 загружаемых MP3/WAV файлов**: все звуки (лазеры, щелчки, подбор бонусов, процедурный фоновый синтвейв) генерируются в реальном времени формулами звуковых волн (Square, Triangle, White Noise).
2. **Локальная БД и менеджер картридж-сейвов** ([`js/storage.js`](js/storage.js)):
   - Рекорды, статистика и разблокируемые достижения хранятся в памяти браузера (`localStorage` / `IndexedDB`).
   - Функция экспорта в файл `.cart` и Drag-and-Drop импорта для переноса прогресса между устройствами.
3. **P2P мультиплеер без игрового сервера (WebRTC DataChannels)** ([`js/p2p.js`](js/p2p.js)):
   - Прямой обмен координатами и инпутами между браузерами игроков.
   - Режим локального Hot-Seat за одной клавиатурой.
4. **Встроенная студия Cartridge Studio** ([`js/editor.js`](js/editor.js)):
   - Пиксельный редактор карт и спрайтов 16×16 с палитрой, возможностью сохранения во флеш-чип или экспорта в PNG.

## 🛰️ Картридж COSMO JUNK: запуск сервера

Исходники игры лежат в [`games/cosmo-junk-game-concept/`](games/cosmo-junk-game-concept/). Проще всего — **автономный сервер без зависимостей**:

```powershell
cd D:\Projects\Gemini\neo_cartridge\games\cosmo-junk-game-concept
node standalone\server.js          # без npm install и PostgreSQL; порт 3000
node standalone\server.js 3100     # или свой порт (ещё вариант: переменная PORT)
```

Комнаты живут в памяти, рекорды пишутся в `standalone/data/leaderboard.json` — база не нужна вообще. Собранный фронтенд уже лежит в `standalone/assets`; пересборка после правки исходников — `node standalone/build.mjs` (подробности в `standalone/README.md`).

Старый путь на Next.js + PostgreSQL (рабочая копия `D:\Projects\cosmo-junk-game-concept`):

```powershell
cd D:\Projects\cosmo-junk-game-concept
npm install          # один раз
npm run dev          # нужен PostgreSQL
docker compose up -d # быстрый PostgreSQL
```

Игра поднимется на `http://localhost:3000`. Если порт занят (например, консоль запущена через `npx serve .` на том же порту), укажите адрес прямо в лаунчере или через параметр:

```
games/cosmo_junk.html?url=http://localhost:3001
```

Быстрый PostgreSQL через Docker Compose:

```powershell
cd D:\Projects\cosmo-junk-game-concept
docker compose up -d
```

Без запущенного сервера картридж показывает экран с инструкцией и кнопкой повторной проверки — консоль при этом продолжает работать.

## 🎨 Стандарты примененных навыков:

* **`oil-ui`**: эстетика портативных инженерных консолей (*Teenage Engineering OP-1 / Playdate*), CRT-шейдер сканлайнов, виньетка и фосфорное свечение.
* **`logo-design`**: векторный картридж с позолоченными контактами и статусный диод ([`logo.svg`](assets/logo.svg), [`favicon.svg`](assets/favicon.svg)).
* **`better-colors` & `better-ui`**: палитра CRT Phosphor Green (`#00FF88`), Cyber Pink (`#FF0055`), Amber Gold (`#FFB800`) и тактильные кнопки со звуковым откликом.
* **`better-accessibility` (WCAG 2.2)**: поддержка клавиатуры (WASD, Стрелки, Space, Enter), фокус-стейты и семантическая разметка.
* **`no-ai-slop` & `better-writing`**: лаконичный, аутентичный инженерный язык без клише.
